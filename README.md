
## Num Codes

Hey there! I built this project to stand out a bit from your typical online portfolio. It's a dynamic and visually rich website, crafted to be an engaging platform for presenting my professional work and skills. Think of it as a digital wizard's workshop where visitors can explore my creations in an intuitive and magical environment. The goal was to build something memorable, highly interactive, and a genuine reflection of my approach to web development.

## Installation

Getting this project up and running on your local machine is pretty straightforward.

1.  **Clone the Repository**:
    Start by cloning the project to your local directory:
    ```bash
    git clone https://github.com/numcodes/portfolio-v3.git
    cd portfolio-v3
    ```

2.  **Install Dependencies**:
    Once you're in the project directory, install all the necessary packages using npm:
    ```bash
    npm install
    ```

3.  **Start the Development Server**:
    After the dependencies are installed, you can fire up the development server:
    ```bash
    npm run dev
    ```
    This will typically start the application on `http://localhost:3000`.

## Usage

Once the development server is running, open your browser and navigate to `http://localhost:3000`.

You'll be greeted by an enchanting home page featuring an interactive 3D wizard model floating amidst a serene, starlit forest. Navigation is handled through a unique circular menu, animated to spin subtly, where each button gracefully guides you to different sections of the portfolio:

*   **Home**: Returns you to the main page.
*   **About**: Discover more about the developer, their journey, and skills, presented alongside an animated 3D hat model.
*   **Projects**: Explore a list of past work, each entry linking to live demos, all within a magical workshop setting, complete with a floating 3D staff.
*   **Contact**: Reach out through an interactive form set against a mystical twilight forest backdrop.
*   **Social Links**: Easily connect via GitHub, LinkedIn, and X (formerly Twitter).
*   **Resume**: Access the developer's resume directly.

The site also features ambient background music with a toggle control, and a responsive design that adapts beautifully to various screen sizes, ensuring a consistent experience across devices. Each page features a dynamically rendered 3D model that enhances the mystical theme.

## Features

*   **Immersive 3D Models**: Engaging 3D wizard, hat, and staff models rendered with Three.js and React Three Fiber.
*   **Dynamic Backgrounds**: Beautifully crafted backgrounds for each section, including a unique firefly animation on the homepage.
*   **Interactive Navigation**: A circular, animated navigation menu that makes exploring the portfolio fun and intuitive.
*   **Smooth Animations**: Leverages Framer Motion for fluid page transitions and interactive elements.
*   **Responsive Design**: Optimized for a seamless experience across all device sizes, from mobile to desktop.
*   **Project Showcase**: A dedicated section to display projects with links and brief descriptions.
